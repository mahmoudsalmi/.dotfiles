# Log collections

[Work area](../README.md)

Use one directory per collection: `YYYY-MM-DD-o-alias/` for an office (lowercase alias) or `YYYY-MM-DD-u-INITIALS/` for a user (uppercase initials). Store standalone logs as gzip with their original filename as the stem; preserve existing archives unchanged. Verify compressed copies and leave the source collection untouched. Search compressed logs in place with `rg --search-zip`.
