## Maintaining the inventory

After changing the contents, run `node "$SD_WORK_DIR/refresh-index.mts"` (Node.js 22.18+; no package install). Tables and trees inside marked blocks are generated; edit the surrounding prose instead. Indexes contain private filenames and are not for publication.
